# Procedure: publish through GitHub Pages

Use this procedure for the approved public GitHub Pages destination.

1. Read INDEX.md, AGENTS.md, README.md, and 02_ARCHITECTURE.md for the current repository and deployment method.
2. Confirm the repository is public and the deployment source matches the documented architecture. Do not change owner or visibility.
3. Build the app with the documented command, if a build step exists. Verify base paths and local font/SVG asset URLs work from the GitHub Pages project subpath.
4. Publish using the configured Pages workflow. Do not add a backend, analytics, or third-party service without approval.
5. Verify the deployed URL loads the game and report the URL, deployed revision, checks performed, and remaining issues.
6. Update README.md and 06_PROJECT_STATUS.md with run/deployment details and resulting state.
