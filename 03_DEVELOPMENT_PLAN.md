# Development plan

**Status:** Proposed sequence only. No milestone is a user-approved schedule.

1. **Close blocking product questions:** zero expansion across locked boundaries; score identity/date ordering; tutorial first-run scope; theme control; input methods; animation/timer precedence.
2. **Choose a small static architecture:** record framework, storage, save format, generation, and deployment choices in 02_ARCHITECTURE.md.
3. **Build board rules:** safe zero start, fixed per-grid mines, cross-boundary clues, revealing/flagging, mistake animation/lives, solve/unlock behavior.
4. **Build persistence and modes:** independent mode saves, strict Time Attack clock, local scores, storage error handling, save import.
5. **Build UI and accessibility:** tutorial, pause menu, dark/light presentation, reduced motion, responsive/keyboard/touch behavior after decisions are set.
6. **Verify and publish:** run the agreed verification plan, then publish through GitHub Pages.

Dependencies: implementation depends on resolving blocking items in step 1 and selecting architecture in step 2. Current progress and immediate next task are in 06_PROJECT_STATUS.md.
